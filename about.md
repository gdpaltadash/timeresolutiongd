# Timer Resolution

Sets the Windows system timer resolution from inside Geometry Dash (same effect as TimerResolution.exe / `NtSetTimerResolution`), so you don't need an external program running.

- Default: 0.5 ms (the finest most systems allow)
- Opts out of Windows 11 power throttling so the setting survives minimizing/occlusion
- Changes apply live from the mod settings
- Releases the resolution when the game closes or the mod is disabled
